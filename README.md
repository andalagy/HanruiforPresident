# The Hanrui Chen Presidential Probability Calculator™

A fully local, fictional satire simulator built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Recharts. No backend, API keys, or external services are required.

## Develop

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

## Validate

```sh
npm test
npm run build
npm run preview
```

Eight sliders update an invented probability live. Calculate Destiny runs the classified scan, unlocks achievements, and captures a downloadable fictional report. Reports describe the last completed calculation; changing controls does not alter an already generated report. Achievement progress persists locally when browser storage is available; Reset clears the simulator but preserves earned achievements.

The seed reproduces the quantum modifier, chart, and sequence of alternate timelines. Reset restores the default seed and sequence. A new seed restarts the timeline sequence. The fantasy timeline explicitly sets 100%; ordinary invented probabilities remain below 100%.

Try the Konami code outside an input: ↑ ↑ ↓ ↓ ← → ← → B A. Reset exits unlimited power mode. Animations respect reduced-motion preferences.

Hanrui Chen is fictional. All probabilities are invented for comedy and carry no scientific or political meaning. “President of North Korea” is an imaginary game title, not a description of the actual political system. Ethnicity and racial background are never calculation factors.
